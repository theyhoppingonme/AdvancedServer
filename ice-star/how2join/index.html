How to Join the Ice Star Server

Joining Steps

  1. Open the original TD2DR game client.
  2. On the server screen, find the "Enter IP" field.
  3. Type in the server address: icestar.com.de
  4. Click Join and you're in!

Important Notes

  • Radmin VPN and ZeroTier-One are not required.
  • The server automatically reboots every day at 3:00 AM UTC (6:00 AM MSK).
