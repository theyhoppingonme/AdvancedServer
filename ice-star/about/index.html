Ice Star - About

A little bit about Ice Star...

The Experimental Server "Ice Star" is a public, unofficial server created for fun and experimentation for Sonic.EXE: The Disaster (2D Remake).

It was the first unofficial public server for the game, making more flexible multiplayer experiences beyond the default.

Purpose

Ice Star is used to test and validate the Advanced Server kernel. As such, it may behave differently during development cycles or feature testing.

When no active testing is underway, it operates with a few minor tweaks for enhanced casual play.
