Advanced Server - Config Configuration

server_config

networking

port
The network port the server listens on.
server_count
Number of parallel server instances.

pairing

maximum_players_per_lobby
Max players per lobby.
ip_validation
Validates players by IP.
ping_limit
Max ping allowed before action.
player_maximum_errors
Max allowed error count before a player is kicked by anticheat.
versioning.target_version
Game version clients should use.
versioning.disable_version_validating
If true, disables version checking.

logging

log_debug
Enables debug log output.
log_to_file
Saves logs to file.

states

lobby_misc

moderation.ban_ip
Enables IP banning.
moderation.ban_udid
Enables UDID banning.
moderation.ban_nickname
Enables nickname banning.
moderation.op_default_level
Default admin level when OPing a player.
moderation.banhammer_friendly_fire
Enables banhammer to affect teammates.
moderation.enforce_whitelist
Only allow whitelisted players.
votekick.cooldown
Time before votekick will be closed.
votekick.autoban_leavers
If true, automatically bans players, who tries to avoid timeout by rejoining the lobby.
message_of_the_day
Text shown to players on join.
lobby_timeout_timer
Max time to wait in lobby before auto-kick.
lobby_start_timer
Delay before lobby starts.
server_location
Specifies server location.
apply_textchat_fixes
Enables text chat compatibility fixes.
authoritarian_mode
Disables votes and lobby-start mechanics, server moderation will handle it instead.
lobby_ready_required_percentage
% of ready players required to start.
kick_unready_before_starting
Whether to kick unready players when game begins.
hosts_name
The name displayed for the host.
anonymous_mode
If true, replaces player names with "anonymous".

map_selection

enabled
Enables map voting.
exclude_last_map
Prevents repeat of previous map.
timer
Voting timer duration.
map_list
Boolean flags for which maps are available.

character_selection

enable
Enables character selection.
charselect_mod_unlocked
Allows same characters chooses.
allow_foreign_characters
Allows modded characters chooses.
charselect_timer
Time allowed for character selection.

gameplay

respawn_time
Time players have to heal their killed mates.
sudden_death_timer
Time before sudden death activates.
ring_appearance_timer
Time when rings appear.
escape_time
Time for escape.
demonization_percentage
% of players becoming EXE pawns.
exe_camp_penalty
Freeze respawn time if EXE camp bodies, giving extra time to revive.
hide_player_characters
If true, all players will have PlaceHolder character.
enable_achievements
Enables achievements on the server.
enable_sounds
Enables in-game sound events.
gametimers_ceiling
Max length of a match.
match_respawn_and_game_timers
Syncs respawn and match timers.
ending_timer
Delay before results will be presented.

anticheat

palette_anticheat
Checks for color palette tampering.
zone_anticheat
Checks if player clips into walls.
distance_anticheat
Detects unusual movement.
ability_anticheat
Detects ability-related exploits.
data_based_anticheat
Other minor cheats detection.

banana

disable_timer
If true, timer is going up. (Last one stands!)
singleplayer
Enables solo play. (Test Mode)

gmcycle

overhell
Enables OverHell game mode. (From IcedCoffee & ColdestTea)

results_misc

enabled
Shows post-game results screen.
timer
Duration of the results screen.
pride
Displays camp teases.

miscellaneous

gui

interface_scale
Adjusts UI scale factor.

other

ignore_inadequate_configuration
Forces server to run with settings that may cause crashes or make the game unfinishable.
