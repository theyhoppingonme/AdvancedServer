Advanced Server - Commands

Command Syntax

All modded commands in the Advanced Server use a colon (:) as the prefix.

Commands inherited from the original server use a dot (.) instead.

New Commands

:status - Shows server statistics.

:chance - Adjusts the player's execution probability.

:stop - Forces the current round to end.

:start - Forces a round to start immediately.

:vm - Allows voting for a specific map.

Admin Commands

:unban - Removes a ban on a player.

:reboot - Restarts the server.

:refresh - Refreshes player configuration data.

Note

Please make sure to use the correct command prefix depending on whether the command is part of this mod or from the original server.
